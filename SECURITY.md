# Security policy

Please report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/olemd/stoppeklokke/security/advisories/new), not as public issues.

Include what you found, how to reproduce it, and the version (shown in the footer). You will get an answer within a week. Fixes are released as soon as possible and credited in the changelog unless you prefer otherwise.

Only the latest release on `main` is supported.
